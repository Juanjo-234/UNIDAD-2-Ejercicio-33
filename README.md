Resolcuión del ejercicio N°33 de la unidad 2 de ñrohramación 2.
Este programa implementa un sistema modular para simular un ciclo de renderizado gráfico utilizando diferentes motores a través de una interfaz común, incorporando validaciones de estado para garantizar una ejecución segura y ordenada de los recursos.

Clases utilizadas
MotorGrafico
RenderizadorOpenGL
RenderizadorDirectX
RenderizadorVulkan
